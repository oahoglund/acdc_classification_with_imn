# Results
The results from running the models are stored in this folder. It is split into results from cross_validation and test_set.
The folders are further divided into classification results and segmentation results. Those are again divied into pr model results.

For each model at least two json files are stored. One that contains logged metrics for a run. The other contains confusion metrics information. In cross validation an additional file info.json is also stored that contrain the location of the first fold of a run in local_log folder. Also in cross validation some models are trained on both predicted segmentation masks (sg) as well as grouth truth segmentation masks (gt).

Most of these files are manually placed into these folders. I copied in the "final" runs for all models, and the info.json are created manually or automatically. If you write a save file you can have the main.py create it, but else you can manually create them with this format:
{
  "local_run_path": "local_log\\runxxx"
}
where you just fill in the run number in the local log.

For imn there is some additional files for feature importance whioch are generated by xai.py

I have left the files from my runs and the ones that appear in the thesis paper (except for image files of any acdc data)
